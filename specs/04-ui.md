# Spec 04 — Web UI (Phase 3, first slice)

Status: **Phase 3a** — playable single-match screen; PWA/service worker and pixel-art
presentation are pending.

## Stack

Vite + React + TypeScript + Tailwind, in `packages/ui`. Mobile-first, retro-scoreboard
aesthetic: monospace, deep-green panels, cream ink, mustard accent.

## Screen

A single match simulator:

- Format selector (Test / ODI / T20).
- Home and away team selectors (content from `@pavilion/data`).
- Venue selector (drives the conditions model).
- Seed input (matches are deterministic and reproducible).
- "Play match" runs `simulateMatch` and renders the result.

Result view: toss, result banner, and per innings a batting card (R, B, 4s, 6s) and bowling
figures (O, M, R, W).

## Commands

```
pnpm dev                      # UI dev server
pnpm --filter @pavilion/ui build
```

Production bundle: ~55 KB gzip JS, ~2 KB gzip CSS.

## Acceptance

- `pnpm --filter @pavilion/ui typecheck` and `build` pass; `pnpm verify` green.
- The UI imports only the public engine and data surfaces.
