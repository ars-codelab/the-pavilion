# Spec 04 — Web UI

Status: **Phase 3b** — match and series modes, offline PWA, device saves. Career screens and
the pixel-art presentation layer are pending.

## Stack

Vite + React + TypeScript + Tailwind, in `packages/ui`. Mobile-first, retro-scoreboard
aesthetic: monospace, deep-green panels, cream ink, mustard accent.

## Screens

Controls: mode (match/series), format (Test / ODI / T20), home and away teams, venue, seed,
and series length. "Play" runs `simulateMatch` or `simulateSeries` (deterministic) and
renders the result.

- **Match view**: toss, result banner, and per innings a batting card (R, B, 4s, 6s) and
  bowling figures (O, M, R, W).
- **Series view**: summary/scoreline, per-match results, and top run-scorers / wicket-takers
  aggregated with `seriesPlayerStats`.
- **Saves**: the current match or series is saved to IndexedDB and can be listed, loaded and
  deleted; loading restores the controls and result exactly.

## PWA

`vite-plugin-pwa` generates a web manifest and a Workbox service worker (auto-update), so the
app is installable and works offline. App icon `public/icon.svg`.

## Commands

```
pnpm dev                      # UI dev server
pnpm --filter @pavilion/ui build
```

Production bundle: ~57 KB gzip JS, ~2 KB gzip CSS, precached for offline use.

## Acceptance

- `pnpm --filter @pavilion/ui typecheck` and `build` pass; `pnpm verify` green.
- The UI imports only the public engine and data surfaces.
